## 项目详情

### 🚀 claw-code

- **仓库**：[ultraworkers/claw-code](https://github.com/ultraworkers/claw-code)
- **语言**：Rust
- **本周新增 ⭐**：189058
- **标签**：（暂无）

这是一个用 Rust 构建的高性能代码工具，号称是 GitHub 历史上最快突破 10 万星标的仓库。基于 oh-my-codex 架构开发，为开发者提供极速的代码处理体验，目前社区热度极高。

**适合谁用**：追求极致性能的后端开发者，以及想体验新一代 Rust 代码工具的技术极客。

### 🚀 awesome-design-md

- **仓库**：[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
- **语言**：未知
- **本周新增 ⭐**：67510
- **标签**：awesome-list, design-md, design-system, design-tokens

这个项目收集了来自知名品牌设计系统的 DESIGN.md 文件模板。只需将设计规范文档拖入你的项目，就能让 AI 编码助手自动生成与之匹配的视觉界面，打通设计与开发的最后一公里。

**适合谁用**：前端开发者、UI/UX 设计师，以及希望借助 AI 快速落地设计系统的技术团队。

---

### 🚀 mempalace

- **仓库**：[MemPalace/mempalace](https://github.com/MemPalace/mempalace)
- **语言**：Python
- **本周新增 ⭐**：50200
- **标签**：ai, chromadb, llm, mcp

目前性能基准测试表现最优的开源 AI 记忆系统，完全免费。它解决了大语言模型上下文有限的痛点，为 AI 助手提供长期记忆能力，支持 ChromaDB 向量存储和 MCP 协议。

**适合谁用**：正在构建 AI Agent 或 LLM 应用的开发者，特别是需要长期记忆和上下文保持功能的场景。

---

### 🚀 caveman

- **仓库**：[JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman)
- **语言**：Python
- **本周新增 ⭐**：49272
- **标签**：ai, anthropic, caveman, claude

这是一个充满趣味的 Claude Code 技能插件，核心理念是"为什么用很多词，少词就行"。通过"洞穴人"式的极简表达风格，最高可减少 65% 的 Token 消耗，既省钱又高效。

**适合谁用**：频繁使用 Claude Code 且关注 API 调用成本的开发者，喜欢尝试新奇 AI 交互方式的用户。

---

### 🚀 career-ops

- **仓库**：[santifer/career-ops](https://github.com/santifer/career-ops)
- **语言**：JavaScript
- **本周新增 ⭐**：40662
- **标签**：ai-agent, anthropic, automation, career

基于 Claude Code 构建的 AI 驱动求职系统，内置 14 种技能模式，配备 Go 语言编写的高性能仪表板。支持 PDF 简历生成、批量投递和全流程自动化管理，让求职效率倍增。

**适合谁用**：正在积极求职的开发者，以及需要批量管理投递流程、优化求职策略的职场人士。

### 🚀 graphify

- **仓库**：[safishamsi/graphify](https://github.com/safishamsi/graphify)
- **语言**：Python
- **本周新增 ⭐**：37317
- **标签**：antigravity, claude-code, codex, gemini

一款支持多平台的 AI 编码助手技能插件，兼容 Claude Code、Codex、Cursor、Gemini CLI 等主流工具。能将任意文件夹中的代码、文档、论文甚至多媒体内容转换为可查询的知识图谱。

**适合谁用**：需要管理复杂代码库或大量技术文档的团队，以及希望构建私有知识库的开发者。

- **本周新增 ⭐**：24869

### 🚀 claude-code

- **仓库**：[claude-code-best/claude-code](https://github.com/claude-code-best/claude-code)
- **语言**：TypeScript
- **本周新增 ⭐**：17161
- **标签**：（暂无）

## 总结

本周 GitHub 趋势明显围绕 AI 编码助手生态爆发，特别是 Claude Code 的周边工具、替代方案和优化插件成为绝对焦点。从记忆系统到 Token 优化，从求职自动化到知识图谱构建，开发者们正在围绕 AI 工作流打造完整的工具链。Rust 在性能敏感型基础设施中表现亮眼，Python 依然是 AI 应用开发的首选，而 TypeScript 则在 CLI 工具和跨平台集成方面占据主导地位。
