## 项目详情

### 🚀 claw-code

- **仓库**：[ultraworkers/claw-code](https://github.com/ultraworkers/claw-code)
- **语言**：Rust
- **本周新增 ⭐**：188815
- **标签**：-

号称"历史上最快突破 10 万 Star"的代码工具，基于 Rust 和 oh-my-codex 构建，性能表现极其出色。项目已解锁，社区活跃度极高，适合追求极致执行效率的开发者关注。

**适合谁用**：对性能敏感的系统开发者、Rust 语言爱好者，以及需要高频代码操作场景的技术团队。

---

### 🚀 awesome-design-md

- **仓库**：[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
- **语言**：未知
- **本周新增 ⭐**：66747
- **标签**：awesome-list, design-md, design-system, design-tokens

收集了众多知名品牌设计系统的 DESIGN.md 文件模板，直接放入项目即可让 AI 编码助手生成风格一致的 UI 界面。解决了 AI 生成界面风格不统一的痛点。

**适合谁用**：前端开发者、UI/UX 设计师，以及使用 Claude、Cursor 等 AI 编程工具希望保持设计一致性的团队。

---

### 🚀 mempalace

- **仓库**：[MemPalace/mempalace](https://github.com/MemPalace/mempalace)
- **语言**：Python
- **本周新增 ⭐**：50014
- **标签**：ai, chromadb, llm, mcp

目前基准测试表现最佳的开源 AI 记忆系统，完全免费。为 LLM 提供长期记忆能力，支持 ChromaDB 向量存储，让 AI 助手能够记住上下文和用户偏好。

**适合谁用**：构建聊天机器人、AI Agent 的开发者，需要为应用添加长期记忆功能的工程团队。

---

### 🚀 caveman

- **仓库**：[JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman)
- **语言**：Python
- **本周新增 ⭐**：48119
- **标签**：ai, anthropic, caveman, claude

一个有趣的 Claude Code 技能插件，通过让 AI 用"穴居人"式的极简语言交流，成功减少 65% 的 Token 消耗。在保持功能完整的同时大幅降低 API 调用成本。

**适合谁用**：重度使用 Claude Code 的开发者、关注 AI 调用成本优化的团队，以及喜欢尝试新奇交互方式的技术极客。

---

### 🚀 career-ops

- **仓库**：[santifer/career-ops](https://github.com/santifer/career-ops)
- **语言**：JavaScript
- **本周新增 ⭐**：40313
- **标签**：ai-agent, anthropic, automation, career

基于 Claude Code 构建的 AI 驱动求职系统，内置 14 种技能模式，支持批量处理、PDF 简历生成和 Go 语言仪表板。实现从职位搜索到申请投递的全流程自动化。

**适合谁用**：正在求职的开发者、需要处理大量简历和职位信息的 HR，以及希望自动化招聘流程的企业。

---

### 🚀 graphify

- **仓库**：[safishamsi/graphify](https://github.com/safishamsi/graphify)

- **本周新增 ⭐**：36449
- **标签**：antigravity, claude-code, codex, gemini

支持 Claude Code、Codex、Cursor、Gemini CLI 等主流 AI 编程助手的技能插件，能将任意代码、文档、图片或视频文件夹转换为可查询的知识图谱，大幅提升大模型对项目的理解能力。

### 🚀 openclaude

- **仓库**：[Gitlawb/openclaude](https://github.com/Gitlawb/openclaude)
- **语言**：TypeScript
- **本周新增 ⭐**：24701
- **标签**：-

开源的 Claude 代码代理 CLI 工具，不仅支持 OpenAI、Gemini、DeepSeek、Ollama 等主流模型，还兼容 200 余种通过 OpenAI 兼容 API 接入的模型，真正实现"一次配置，多模型切换"。

**适合谁用**：需要灵活切换不同大模型的开发者、偏好开源 CLI 工具的技术人员，以及希望避免 vendor lock-in 的团队。

### 🚀 claude-code

- **仓库**：[claude-code-best/claude-code](https://github.com/claude-code-best/claude-code)
- **语言**：TypeScript
- **本周新增 ⭐**：17070
- **标签**：-

原汁原味的 Claude Code 可运行版本，完整修复了 TypeScript 类型定义，提供企业级可靠性。lock 文件保真，支持 bun 一键安装和启动，适合二次开发和本地部署。

**适合谁用**：希望深度定制 Claude Code 的开发者、对代码安全性和可审计性有要求的企业用户，以及喜欢自建 AI 开发环境的极客。

## 总结

本周 GitHub 趋势明显围绕 AI 编码助手生态展开，特别是 Claude Code 的周边工具和技能插件呈现爆发式增长。从降低 Token 消耗的"caveman"到增强长期记忆的"mempalace"，开发者们正在全方位优化 AI 编程体验。同时，多模型支持和开源替代方案也成为主流趋势，反映出社区对 AI 工具链灵活性和成本控制的高度重视。
